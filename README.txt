KSR DTP Question Paper Maker V1.0
1. Open index.html in Chrome for local use, or upload all files to GitHub Pages.
2. Paste MCQ questions in the large box.
3. Click Generate Preview.
4. Click Print / Save PDF and choose A4 / Save as PDF.
5. Correct answers may be marked with ●, •, *, ✓ or ✔. Student paper can remove these marks automatically.
6. Answer Key opens a separate detected answer list.
